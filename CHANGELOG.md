# Changelog

## Version 1.0 - Baseline Acquisition System

- Added the original Spike Recorder Arduino acquisition code.
- Configured analog signal acquisition through A0.
- Configured Timer1-based sampling.
- Added circular sample buffering.
- Added USB serial communication for transmission of acquired data.

## Version 1.1 - Project Documentation

- Added project overview and objectives.
- Documented hardware and software components.
- Documented the heart sound acquisition workflow.

## Version 1.2 - QA Documentation

- Added QA test results.
- Added root-cause analysis.
- Added measurement-based verification using previously recorded WAV files.

## Experimental Evidence

Previously recorded heart-sound WAV files were analyzed to verify the recorded signal characteristics.

The analyzed recordings have a sampling frequency of 10,000 Hz and one audio channel.
